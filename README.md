# Agenda Gravel — 100 km autour de Toulouse

Ce dépôt contient un agenda de manifestations gravel annoncées dans un rayon approximatif de 100 km autour de Toulouse.

## Mise à jour

Les événements sont actuellement vérifiés et ajoutés **manuellement** dans `events.json`. Aucune synchronisation automatique n’est installée. Les informations peuvent évoluer : vérifier les liens sources avant déplacement.

Pour actualiser, modifier `events.json` sur GitHub et valider avec **Commit changes**. La page GitHub Pages lit automatiquement le fichier à chaque ouverture.

Champs : `date` (AAAA-MM-JJ), `end_date` (facultatif), `title`, `location`, `details`, `source`.
